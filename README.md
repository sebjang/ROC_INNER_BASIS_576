## 근거 예규

> **금융세제과-576** — 외국 ETF의 자본금 환급에 따른 배당에 대한 배당소득 과세 여부
>
> 해당 ETF를 취득하기 위하여 사용한 금액을 **초과하는 부분에 한하여 의제배당으로 과세**

```
이내분   = MIN(누적 ROC, 취득원가)      … 원금반환, 과세 아님
의제배당 = MAX(0, 누적 ROC − 취득원가)  … 「소득세법」 §17① 의제배당
```

누적 ROC와 취득원가는 발행사 확정자료(8937 · ICI Primary · 1099-DIV)와 증권사 원장에서 확인된 금액이어야 합니다. 본 계산기는 위 산식을 **표기만 하며 판정하지 않습니다.** 산정된 이내분은 「① ROC 취득가이내분 감액」에 이용자가 직접 입력합니다.

## 기능

- 금융소득 종합과세와 「소득세법」 제62조 **비교과세** 계산구조 재현
- 신고서 **⑰ 산출세액계산서(금융소득자용)** 전개 순서 그대로 표시
- 신고서 PDF 판독 — **홈택스 미리보기형**과 **전자신고제출분** 양식 모두 지원
- 판독값과 계산값 **24개 항목 자동 대조**
- 경정 시나리오 6종 입력 → 정본열·경정열·차이 동시 표시
- 상태 저장/복원(.json), 인쇄

## 계산하지 않는 것

외국납부세액공제 한도(§57), 감면, 가산세, 농어촌특별세, 개인지방소득세는 산출하지 않습니다. 지방소득세는 결정세액의 10%로 위택스에 별도 신고합니다.

## 배포 절차

1. `index.html` 수정
2. `node verify_hash.js index.html` — 지문 확인, 어긋나면 `LOGIC_HASH` 갱신 후 재실행
3. `node bump.js 2026-08-28c` — BUILD 표기 3곳과 README 의 버전·지문을 한 번에 갱신
4. README 변경 이력의 내용란을 채움
5. `node release_check.js` — 지문 3곳·BUILD 4곳 대조
6. `vendor/` 폴더(`pdf.min.js` · `pdf.worker.min.js` · `cmaps/` · `standard_fonts/`)가 함께 올라갔는지 확인
7. 커밋·푸시 후 공개 주소에서 상단 BUILD 표기와 하단 지문을 눈으로 확인
