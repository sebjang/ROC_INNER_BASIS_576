# 종합소득세 계산기 — 금융소득 종합과세

BUILD 2026-08-27b 
미리보기형/전자신고제출분 양식 판독

**BUILD 2026-08-23e**

금융소득 종합과세와 소득세법 §62 비교과세를 신고서 ⑰ 산출세액계산서(금융소득자용)
전개 순서 그대로 재현하는 단일 HTML 계산기.

화면 제목 아래에 표시되는 BUILD 값이 위와 다르면 캐시된 옛 파일이다.

**입력값은 브라우저 안에서만 처리되며 서버로 전송되지 않는다.**

## 사용

브라우저에서 `index.html` 을 열거나 GitHub Pages 주소로 접속한다.
설치와 회원가입이 없고 인터넷 연결 없이도 동작한다.

## 기능

- 금융소득 2천만원 초과 → 종합과세 · §62 비교과세 (⑩~㊵)
- 금융소득 2천만원 이하 → 분리과세 종결 (㉜~㊴)
- 원천징수되지 않은 이자·비영업대금·배당(②③⑦) 별도 세율 처리
- 비영업대금이익 25% / 14% 구분(①⒜) 및 ㉒ 비교산출세액 반영
- 귀속연도별 세율표 자동 전환 (2022년 이전 / 2023년 이후)
- Gross-up 가산율 자동 판별 (배당세액공제와 대조하여 역산)
- **홈택스 신고서 PDF 판독** — 끌어놓거나 텍스트 붙여넣기
- 판독한 신고서 값이 그 연도의 검증 기준으로 자동 등록되어 즉시 대조
- 상태 저장·복원 (JSON)
- 인쇄 전용 스타일 (A4 세로 · 텍스트 보존)

## 검증 (BUILD 2026-08-23e 기준)

실제 신고서로 대조하여 확인하였다. 배포본에는 어떤 실제 신고자료도 포함하지 않는다.

| 귀속 | 과세방식 | 세율구간 | 검증 항목 | 결과 |
|---|---|---|---|---|
| 2022 | 종합 | 24% | 18 | 전건 일치 |
| 2023 | 종합 | 24% | 15 | 전건 일치 |
| 2024 | 종합 | 40% | 13 | 전건 일치 |
| 2025 | 분리 | — | 9 | 전건 일치 |
| 2024 (별건) | 종합 | 24% | 18 | 전건 일치 |
| 2024 (별건) | 종합 | 24% · 비영업대금 | 18 | 전건 일치 |

Gross-up 가산율은 신고서에서 역산하여 확인하였다 — 2022·2023년 11%, 2024년 이후 10%.

### 검증 방식

배포되는 `index.html` 의 계산 코드를 그대로 실행하여 두 경로로 대조한다.

1. **배포본 ↔ 신고서** — 실제 신고서 값과 항목별 대조
2. **배포본 ↔ 독립 재현 엔진** — 같은 산식을 별도로 구현하여 상호 대조

두 경로가 모두 일치할 때만 통과로 본다. 재구현만 검증하면 배포 파일 자체는 보증되지 않는다.

```
사례 6 · 검증항목 95 · 신고서 대조 불일치 0 · 경로간 불일치 0
PDF 판독 36항목 · 불일치 0
경정 시나리오 8건 · 정본열 불변 확인
```

과세표준이 두 종류인 점에 유의한다.
`❹21 = 종합소득금액 − 소득공제` 이고 `⑰ = ⑮ − ⑯` 이며 둘의 차이는 종합과세기준금액 2천만원이다.

## 산출하지 않는 것

- 외국납부세액공제 한도 (§57)
- 세액감면 · 가산세 · 농어촌특별세
- 지방소득세는 결정세액의 10% 로 표시만 하며 위택스 별도 신고 사항이다

## 경정 시나리오

경정 전용 입력 6칸으로 과표 감액·증액, 세액공제 증액, 기납부 증감을
경정열에만 반영한다. 정본열은 신고서 그대로 유지되므로
검증을 살린 채 시나리오를 비교할 수 있다.

| 칸 | 항목 | 방향 | 반영처 |
|---|---|---|---|
| ① | ROC 취득가이내분 | 감액 | 배당 — 그 외 |
| ② | 배당 — 그 외 | 증액 | 배당 — 그 외 (음수 가능) |
| ③ | 배당 원천세 과다징수 | 감액 | 기납부세액 |
| ④ | 외국납부세액공제 §57 | 증액 | 세액공제 |
| ⑤ | 그 밖의 세액공제 | 증액 | 세액공제 |
| ⑥ | 기납부세액 | 증액 | 기납부세액 (음수 가능) |

여섯 칸이 모두 0 이면 경정열은 정본열과 같다.
